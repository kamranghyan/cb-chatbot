HTTP transport — real request/response

This widget is wired to protocol: { type: 'http' }, calling a real local server (not mock data).

  1. Run node server.js in this folder (starts on port 4000)
  2. Serve this page (e.g. npx serve . from this folder)
  3. Open it and chat — replies now come from a real HTTP POST

Try typing hello, pricing, or error (to see error handling).
