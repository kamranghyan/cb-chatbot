WebSocket transport — persistent connection + streaming

This widget is wired to protocol: { type: 'websocket' }. Replies stream in word-by-word over a real, persistent socket connection (not HTTP).

  1. cd example/websocket-transport && npm install (first time only)
  2. Run node server.js (starts on port 4001)
  3. Serve this page (e.g. npx serve . from this folder)
  4. Open it and chat — watch the status dot go Online, and replies stream in

Try disconnecting the server (Ctrl+C) while chatting, then restarting it — the widget auto-reconnects with backoff and the status dot reflects each state.
