Stream transport — SSE, OpenAI-style token streaming

This widget is wired to protocol: { type: 'stream' }. The reply streams in token-by-token over Server-Sent Events — the same framing OpenAI/Anthropic-style LLM APIs use.

  1. Run node server.js in this folder (starts on port 4002)
  2. Serve this page (e.g. npx serve . from this folder)
  3. Open it and chat — watch the reply type itself out live

Try the "Stop generating" button mid-reply to test cancellation.
